YtDown — это бесплатный и легкий open-source инструмент для простого скачивания видео с YouTube. Без лишних настроек и сложной конфигурации: вставьте ссылку и получите файл в максимальном качестве.

    ОБЯЗАТЕЛЬНОЕ ТРЕБОВАНИЕ ДЛЯ ЛОКАЛЬНОГО ЗАПУСКА
    Перед запуском программы ОБЯЗАТЕЛЬНО положите файлы ffmpeg.exe и ffprobe.exe в одну папку рядом с .py файлом проекта! Без них склейка и обработка видео работать не будут.

Запуск из исходного кода

Если вы хотите запустить проект локально:

    Положите файлы ffmpeg.exe и ffprobe.exe в папку с app.py файлом.

    Установите зависимости и запустите скрипт:
    
pip install -r requirements.txt
python main.py
