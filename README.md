           YtDown
1. Установите зависимости

pip install flask flask-cors yt-dlp

2. Скачайте ffmpeg.exe и ffprobe.exe и поместите в папку проекта.

3. Запустите:
python app.py

4. Откройте в браузере: http://localhost:5000
    Требования

    Python 3.12+

    Node.js (для работы yt-dlp)

    ffmpeg.exe + ffprobe.exe (в папке проекта)

Установка всех зависимостей одной командой

pip install flask flask-cors yt-dlp

Для пользователей Windows

Скачайте Python (Add to PATH) + Node.js

    Установите зависимости и запустите скрипт:
    
pip install -r requirements.txt
python main.py
